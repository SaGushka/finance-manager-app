# Дизайн мобильного приложения "Финансовый Менеджер"

## Обзор

Мобильное приложение для управления личными финансами с функциями автоматической категоризации расходов и построения прогнозов. Приложение разработано в соответствии с Apple Human Interface Guidelines для обеспечения нативного iOS-опыта.

## Цветовая схема

### Основные цвета
- **Primary (Акцент)**: `#2563EB` (синий) — основные кнопки, активные элементы
- **Background**: `#FFFFFF` (светлый) / `#0F172A` (темный)
- **Surface**: `#F8FAFC` (светлый) / `#1E293B` (темный) — карточки
- **Foreground**: `#0F172A` (светлый) / `#F8FAFC` (темный) — текст
- **Muted**: `#64748B` — вторичный текст

### Цвета категорий расходов
- **Продукты**: `#22C55E` (зеленый)
- **Транспорт**: `#3B82F6` (синий)
- **Развлечения**: `#A855F7` (фиолетовый)
- **Рестораны**: `#F97316` (оранжевый)
- **Здоровье**: `#EF4444` (красный)
- **Одежда**: `#EC4899` (розовый)
- **Коммунальные услуги**: `#06B6D4` (голубой)
- **Другое**: `#6B7280` (серый)

### Цвета состояний
- **Success**: `#22C55E` — доходы, положительные изменения
- **Warning**: `#F59E0B` — предупреждения о превышении бюджета
- **Error**: `#EF4444` — расходы, отрицательные изменения

## Список экранов

### 1. Главный экран (Home)
**Назначение**: Обзор финансового состояния пользователя

**Содержимое**:
- Общий баланс (крупный текст в центре)
- Карточки с доходами и расходами за текущий месяц
- Быстрые действия: "Добавить расход", "Добавить доход"
- Список последних 5 транзакций
- Мини-график расходов за неделю

### 2. Экран транзакций (Transactions)
**Назначение**: Полный список всех операций

**Содержимое**:
- Фильтр по периоду (неделя/месяц/год)
- Фильтр по типу (доходы/расходы/все)
- Список транзакций с группировкой по дате
- Каждая транзакция: иконка категории, название, сумма, дата
- Поиск по названию транзакции
- FAB кнопка для добавления новой транзакции

### 3. Экран добавления транзакции (Add Transaction)
**Назначение**: Создание новой транзакции

**Содержимое**:
- Переключатель "Расход / Доход"
- Поле ввода суммы (крупный числовой ввод)
- Поле описания транзакции
- Выбор категории (сетка иконок)
- Выбор даты
- Кнопка "Сохранить"

### 4. Экран аналитики (Analytics)
**Назначение**: Визуализация финансовых данных

**Содержимое**:
- Переключатель периода (неделя/месяц/год)
- Круговая диаграмма расходов по категориям
- Столбчатая диаграмма доходов/расходов по дням
- Список топ-5 категорий расходов
- Сравнение с предыдущим периодом

### 5. Экран прогнозов (Forecast)
**Назначение**: Прогнозирование будущих расходов

**Содержимое**:
- Прогноз расходов на следующий месяц
- Линейный график тренда расходов
- Рекомендации по экономии
- Предупреждения о превышении бюджета
- Прогноз по категориям

### 6. Экран настроек (Settings)
**Назначение**: Настройки приложения

**Содержимое**:
- Валюта (выбор из списка)
- Месячный бюджет (ввод суммы)
- Тема (светлая/темная/системная)
- Экспорт данных
- О приложении

## Ключевые пользовательские потоки

### Добавление расхода
1. Пользователь на главном экране нажимает "Добавить расход"
2. Открывается экран добавления транзакции
3. Пользователь вводит сумму
4. Вводит описание (например, "Пятерочка")
5. Система автоматически предлагает категорию "Продукты"
6. Пользователь подтверждает или меняет категорию
7. Нажимает "Сохранить"
8. Возврат на главный экран с обновленным балансом

### Просмотр аналитики
1. Пользователь переходит на вкладку "Аналитика"
2. Видит круговую диаграмму расходов за текущий месяц
3. Нажимает на сегмент "Продукты"
4. Видит детализацию расходов в этой категории
5. Переключает период на "Год"
6. Видит годовую статистику

### Просмотр прогноза
1. Пользователь переходит на вкладку "Прогноз"
2. Видит прогнозируемые расходы на следующий месяц
3. Видит предупреждение о возможном превышении бюджета
4. Читает рекомендации по экономии
5. Просматривает прогноз по категориям

## Навигация

### Tab Bar (нижняя навигация)
1. **Главная** (house.fill) — Home Screen
2. **Транзакции** (list.bullet) — Transactions Screen
3. **Аналитика** (chart.pie.fill) — Analytics Screen
4. **Прогноз** (chart.line.uptrend.xyaxis) — Forecast Screen
5. **Настройки** (gear) — Settings Screen

## Компоненты

### TransactionCard
- Иконка категории (цветной круг с символом)
- Название транзакции
- Категория (мелкий текст)
- Сумма (зеленый для дохода, красный для расхода)
- Дата

### CategoryBadge
- Цветной фон категории
- Иконка категории
- Название категории

### BalanceCard
- Крупная сумма баланса
- Подпись "Текущий баланс"
- Мини-индикатор изменения

### QuickActionButton
- Иконка действия
- Текст кнопки
- Цветной фон

## Автоматическая категоризация

### Правила на основе ключевых слов
Система анализирует описание транзакции и автоматически присваивает категорию:

| Ключевые слова | Категория |
|----------------|-----------|
| пятерочка, магнит, перекресток, ашан, лента, продукты | Продукты |
| яндекс такси, uber, метро, автобус, бензин, заправка | Транспорт |
| кино, театр, netflix, spotify, игры | Развлечения |
| ресторан, кафе, макдональдс, kfc, доставка еды | Рестораны |
| аптека, врач, клиника, анализы | Здоровье |
| zara, h&m, одежда, обувь | Одежда |
| квартплата, электричество, интернет, связь | Коммунальные услуги |

## Прогнозирование

### Метод скользящего среднего
- Анализ расходов за последние 3 месяца
- Расчет среднего значения по каждой категории
- Учет сезонности (праздники, отпуск)
- Экстраполяция на следующий месяц

### Визуализация
- Линейный график с историческими данными
- Пунктирная линия прогноза
- Зона неопределенности (±10%)
